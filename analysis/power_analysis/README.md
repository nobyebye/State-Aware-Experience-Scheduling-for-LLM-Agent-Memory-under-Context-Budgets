# 校准与测试的功效模拟（零调用）

- 当前版本：`power_v2.py`（结果 `results_power_v2.txt`），研究计划第四版表 7-1 据此生成（2026-10-22 修订后重跑）。
- 运行（项目根目录或任意目录均可，依赖 Python ≥ 3.10 与 numpy；本次结果用 numpy 2.5.3）：

  ```
  python analysis/power_analysis/power_v2.py --bootstrap-check 300 > analysis/power_analysis/results_power_v2.txt
  ```

  默认读取 `analysis/n_runs_extract.jsonl`（SHA-256 前 16 位 `15ced1a5007a597a`，输出首行会打印）；随机种子 20261022；每种情形 2,000 次。
- 目标总体：开发集题目的等权分布（每题 1/110），与正式分析的按题平均一致。
- 抽样：目标集每个大小为 k 的组，按组大小成比例抽一个开发集题目组，再在组内有放回抽 k 道题；
  每个题目位的边际分布因此是题目等权，与校准 b 时使用的分布一致。
- 校准：压缩条件在 logit 尺度加 b + σ·z（σ = 0/0.5/1.0）；E_z 用 Gauss–Hermite 求积（80 点，与 160 点之差 < 1e-9），二分法求 b。
- 情形：Δ = 0、−2、−5 个百分点；Δ = −5 时的通过率是边界误判率（名义 0.025）。
- 自检：每种情形核对模拟样本的期望差与估计量均值是否在蒙特卡洛误差内等于 Δ；不通过则不输出该情形的通过率，脚本以退出码 1 结束。
- `--bootstrap-check N`：部分情形下比较线性化区间与按组 bootstrap 区间（与 `src/prism_thesis/stats.py` 相同口径）。
- 模型局限：各题效应独立、两臂独立二项抽样，未包含组级共同效应与同题两臂的正相关；需在配对试运行后做敏感性分析。
- 修订记录（2026-10-22）：修订前等概率抽组，题 i 的边际概率为 1/(67·k_i)，与按题等权校准不一致，
  异质情形下实际平均差偏离设定值（σ = 1、Δ = −2 时约 −1.3～−1.6）；参考随机数只有 200 行。两处均已修正。
- `power.py`（第一版，已废弃）：±0.5 调整被截断到 [0,1]，导致“真实差为 0”的异质情形实际约为 −1 个百分点，且按组平均；不再使用。
