# 补充实验预先登记：PRISM 的组合候选（2026-11-08，测试集运行之前写定）

## 背景

主实验（预先登记）中 prism@8 在测试集上不劣于完整记忆注入（+0.18pp，95% 区间 [−4.75, +5.30]），平均输入 1905 token，
节省 27%。事后分析发现，PRISM 在“上一步 SQL 成功执行后”的轮次只能省略 fn_other：各组风险取单组留一消融的 95% 上界
（5–20pp）并按加法合成，几组同时省略的风险被高估。开发集诊断实验（docs/诊断实验_成功后整块删除_20261107.md）直接测量了
几种整块省略的联合风险，显示联合风险远小于单组上界之和。

## 方法修订（PRISM-bundle）

- 风险表增加“组合组”：开发集诊断实验中做过联合消融的四个组合（只在成功执行后的轮次）：
  B1 全部示例 = exp_top1 + exp_rest；
  B2 表信息与规则 = one_stmt + scope + fn_predicted + fn_other + schema；
  B3 表信息与示例 = schema + exp_top1 + exp_rest；
  B4 整块 = B2 ∪ B1 ∪ repair。
  组合的风险 = 联合消融相对 full 的成功率下降的 95% 题目组 bootstrap 区间上界（与单组条目相同的估计方法、相同的
  最少暴露题目组要求 10），按任务类型分别估计。数据：results/diag/after_success.jsonl（开发集，每题 5 次，
  自带 full 对照）。原风险表的单组条目不变。
- 每轮选择：候选为单组与适用的组合；选中的候选两两不得包含同一组；在 Σ风险 ≤ ε 内最大化省略的 token
  （精确求解：枚举两两不相交的组合子集，其余单组用原 0-1 背包）。组合中任一组被错误补回强制保留时，该组合不可选。
  其余部分（状态识别、经验检索、错误补回、布局）与 prism@ε 完全相同。
- 条件名 prism-bundle@ε，风险表 results/risk/risk_table_bundles.json。

## 假设与判定（补充，探索性）

- H-S1（主）：prism-bundle@8 在测试集上不劣于 full（与主实验相同的 δ = 5pp、题目加权、题目组聚类 bootstrap
  95% 区间下界 > −5pp）。
- H-S2：prism-bundle@8 在测试集上的平均输入 token 低于 prism@8（1905）。
- 运行顺序：先在构建集上运行 prism-bundle@8（每题 10 次），与 calib_v2 中的 full 配对检验非劣；
  只有构建集通过，才在测试集上运行 prism-bundle@8（每题 10 次），否则报告构建集未通过、不运行测试集。
- ε 固定为主实验校准得到的 ε* = 8，不重新搜索。

## 需要在论文中说明的事项

- 修订是在看到测试集结果之后提出的；测试集第二次被使用。结论只作为补充、探索性证据，主结论仍以预先登记的
  prism@8 为准。
- 组合的定义来自开发集诊断（其中 B4 对应人工阶段切换基线在成功后的省略规则），没有使用测试集信息选择组合。
