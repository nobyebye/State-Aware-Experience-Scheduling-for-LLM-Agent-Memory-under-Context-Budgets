# 预实验：PRISM-JS（联合删除搜索）预先登记（2026-11-09，运行前写定）

## 目的

PRISM 把各单元组省略风险的上界相加，所以在成功执行后不敢整块省略。PRISM-JS 改为直接测量整套省略方案的联合损失，
每个状态只加一个上界，用 λ 串起一族策略。本预实验先快速比较各方法，再决定是否做正式实验。

## 方法

- 检索与 PRISM / phase_switch 相同（状态感知检索）。出错后发送全部候选；补回映射与 PRISM 相同。
- 搜索路径事先固定（`analysis/js_search.py` 中的 `PATHS`），每一步在上一步基础上累积省略：
  - 初始：fn_other → +answer_query, empty_scalar → +insight → +observe, rounds, modify_answer → +exp_rest
  - 成功执行后：exp_rest → +exp_top1 → +fn_other, fn_predicted → +schema, one_stmt, scope → +insight → +observe, rounds, modify_answer → +answer_query, empty_scalar
- 每个层（状态 × 预测任务类型）的每一步：联合损失 = js-ref − js-abl（按题配对，题目组 bootstrap），取 97.5% 上界 U 和每题平均节省的 token V。
- 对每个 λ 和每种任务类型，从初始层和成功后层各选一步：在 max(U_初始, 0) + max(U_成功后, 0) ≤ λ 的约束下，使 V 之和最大。
  λ ∈ {2, 4, 6, 8, 10, 12, 16}。

## 数据

- 搜索：开发集 110 题，13 个条件（js-ref + 12 个联合省略），每题 3 次，共 4290 次运行。
- 预实验比较：构建集按题目组切分（`scripts/make_pilot_split.py`，种子 20261109，结果在 `configs/pilot_split.json`）。
  - 其中 60 组 / 69 题作为预实验集；
  - 其余 182 组 / 203 题留作正式校准，预实验不使用。
  - 比较条件：full、js-ref、prism@8、prism-bundle@8、phase_switch、js@4、js@8、js@12、js@16，每题 3 次，共 1863 次运行。
- 测试集不参与预实验。

## 之后的正式实验（视预实验结果决定）

- 冻结 js_table 后，在构建集的校准部分（203 题，每题 10 次）上，按 λ 从小到大做固定序列非劣检验（δ = 5pp），选出 λ*。
- 然后在测试集上与 full、PRISM、phase_switch 比较（每题 10 次）。
- 迁移实验：换用 extended prompt，phase_switch 照搬原规则，PRISM-JS 重新搜索。

## 运行

在 VM 的仓库根目录执行 `bash scripts/run_js_pilot.sh`（第 0 步是不花钱的演练），费用约 0.3 美元。
